# Oferta y traspaso
Ofrecer instalación de actas colaborativas para equipos, configuración de marca permitida, carga manual de plantillas, formación, backup supervisado y mantenimiento. Cotizar instalación y mensualidad según usuarios, almacenamiento, retención y soporte; son propuestas comerciales, no métricas de rentabilidad ni tarifas de terceros verificadas. No prometer firma electrónica, gestión documental regulada, MFA local o aislamiento multicliente.

Plantillas en plantillas/: copiar contenido en notas nativas nuevas, revisar permisos y asignar responsables. No se importan ni publican automáticamente.

Odoo: exportar Markdown/HTML de cada nota y adjuntar el documento final a proyecto/tarea/cliente según módulos y permisos disponibles. Para Moodle/Nextcloud se pueden entregar los mismos archivos exportados. Migración completa a otro motor requiere mapear cuentas, historial, enlaces y adjuntos; una exportación de documento no transfiere usuarios ni permisos. Para migrar HedgeDoc completo usar respaldo DB+uploads y conservar la versión; revisar dominios absolutos. No se incluye conector API implementado ni sincronización bidireccional.
